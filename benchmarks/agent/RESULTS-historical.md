# Agent chart-reading benchmark: results

Generated by `run.py` from `results.jsonl`; method and reading in [README.md](README.md).

- model `claude-sonnet-5-5` via `claude -p`, one call per chart and format with all of that chart's questions, one run per tag, no repeats
- formats: `text` = `render(fig, cols=80).text`, `summary` = `RenderResult.summary()`, `image` = PNG, `mpl_ascii` and `plotext` = those packages' text from the same figure, `none` = no chart, `hybrid` = `render(fig, 60, ascii=True, rows=12)` text then that result's `summary()`; `ascii` = `render(fig, 80, ascii=True, rows=16).text`; `ascii_tall` = `render(fig, 80, ascii=True).text` (default height)
- tags: `before` = the renderer at c1f6de5 (the first benchmark), `after` = this renderer; the dev split (`charts.py`) was used to tune `after`, the held-out split (`heldout.py`) was written before any change and only checked
- PNG 640×480 px (matplotlib default 6.4×4.8 in, 100 dpi); Anthropic's documented estimate width×height/750 = 410 tokens; tables use the API's count
- chart tokens: the call's input tokens as the API reports them (Claude tokenizer), minus the same chart's `none` call; output tokens include the model's hidden reasoning (the replies are a short JSON object)
