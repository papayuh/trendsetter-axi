# Agent chart-reading benchmark: results

Generated by `run.py` from `results.jsonl`; method and reading in [README.md](README.md).

- 81 questions on 25 charts; formats: `text` = `render(fig, cols=80).text`, `summary` = `RenderResult.summary()`, `image` = PNG, `mpl_ascii` and `plotext` = those packages' text from the same figure, `none` = no chart
- model `claude-sonnet-5-5` via `claude -p`, 150 calls (one per chart and format, all of that chart's questions in one call), one run, no repeats
- PNG 640×480 px (matplotlib default 6.4×4.8 in, 100 dpi); Anthropic's documented estimate width×height/750 = 410 tokens; tables use the API's count
- chart tokens: the call's input tokens as the API reports them (Claude tokenizer), minus the same chart's `none` call
- output tokens include the model's hidden reasoning; the replies themselves are a short JSON object. Calls ran one at a time; `mpl_ascii` and then `plotext` calls ran in later passes, so their latency is from a different stretch of time
- mpl_ascii raised on 1 chart(s) (`line_log_users`); that call got the error in place of a chart
